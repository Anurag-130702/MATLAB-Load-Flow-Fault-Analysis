# MATLAB-Based Load Flow & Fault Analysis Simulation

This project simulates a simple electrical power system under normal, overload, and fault conditions using MATLAB.

## Objectives

- Analyze current variation under different load conditions
- Study voltage drop across line resistance
- Calculate power loss under increasing load current
- Detect overload conditions using a current threshold
- Simulate fault current variation with different fault resistance values

## Concepts Used

- Ohm's Law
- Voltage Drop
- Power Loss
- Overload Detection
- Fault Current Analysis

## Tools Used

- MATLAB Online
- MATLAB Script

## Project Outputs

### 1. Current Variation Graph

Shows how current increases as load resistance decreases.

### 2. Voltage Drop Graph

Shows increased voltage drop under high current conditions.

### 3. Power Loss Graph

Demonstrates higher transmission losses during overload conditions.

### 4. Fault Current Graph

Shows rapid increase in fault current as fault resistance decreases.

## Key Observations

- Lower resistance causes higher current flow.
- Higher current increases voltage drop and power loss.
- Low fault resistance causes very high fault current.
- Protective systems are important in power systems.
